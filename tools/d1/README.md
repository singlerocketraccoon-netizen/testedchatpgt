# Генератор d1

Из корня репозитория: `python tools/d1/build.py` (Python 3.12+, только стандартная библиотека).

`data.json` содержит 10 стран, 10 услуг, три полных реальных отзыва, сведения об источниках и размеры изображений. `country()` и `service()` в build.py — шаблоны типов страниц; header(), footer(), contact(), emit() — общие компоненты и каркас. HTML записывается в docs/scheme2/d1/ и коммитится вместе с исходными данными. На клиенте ничего не подгружается.

`templates/home-source.html` — снимок главной до этой задачи. Генератор меняет в нём только шапку, её поддержку в head/спрайте, адреса ссылок и марку в подвале, которую владелец явно попросил заменить светлым логотипом. Остальные блоки остаются побайтово прежними. Не редактируйте эту копию для изменения внутренних страниц.

Шрифты и общие фотографии читаются из существующих assets по относительным путям. Новые PNG логотипов скопированы из корня репозитория без изменения. Фавиконки экспортированы из знака. Многоразовый запуск даёт тот же HTML; CSS и JS генератор не перезаписывает.

Тексты страницы «Как мы работаем» требуют согласования: подходящего файла в корне репозитория на исходном коммите не было. Визы, маршруты, цены, новые описания услуг, характеристики команды, реквизиты и правовые тексты имеют data-needs-approval. Общие климатические шкалы — ориентиры, не прогноз. Несколько фото обозначают образ пляжного отдыха, а не подтверждённый курорт или отель; подписи это уточняют. Канонический домен devfriends.ru требует подтверждения владельца; до публикации сохранён noindex.

Локальные проверки и захват скриншотов выполняются отдельно; в screens/pages/index.html находится галерея. С сайта нет ссылок на технические оглавления.

Снимки: `python tools/d1/screens.py` (Playwright, Chromium, Pillow). Снимаются 38 страниц, включая дизайн-систему без технического оглавления и страницы акцентов: 390 px @2x и 1440 px @1x, JPEG 75. Ещё шесть кадров показывают раскрытый блок отдыха, карусель предложений и открытое окно подбора на обеих ширинах. Перед съёмкой — reduced motion, прокрутка вниз и обратно, ожидание шрифтов/фото и 500 мс. Галерея пересобирается автоматически; устаревшие JPEG удаляются.

10 ноября владелец разрешил публикацию всего комплекта и потребовал проверить лицензии. `photo_replacements` в data.json заменяет четыре неподтверждённых изображения старого сайта на локальные Unsplash WebP, в том числе на главной. Реестр всех используемых фото и лицензий — docs/scheme2/d1/img/sources.json. Историческая копия home-source.html остаётся нетронутой; build.py применяет разрешённые замены при сборке.

Сотрудники подробной страницы команды задаются в `team_members` (фото, имя, инициалы, роль, специализация, MAX и Telegram). `team_content()` собирает карточки: до четырёх — сетка, больше — карусель; на телефоне всегда горизонтальная прокрутка. `page_overrides` меняет метаданные и отображаемый H1 конкретной страницы, сохраняя краткие подписи в меню и каталогах.

Этап 1: `home_rest`, `selection`, `home_process`, `review_platforms` в data.json задают новые блоки главной и ссылки на карты. В home-source.html для блока отдыха и окна используются слоты; остальные блоки сохраняются. Три вопроса окна находятся в HTML, JS только переключает состояния и локально проверяет телефон/согласие. Страницы `otdyh/…/index.html` собраны на этапе 2 шаблоном rest.py; эти переходы теперь ведут на готовые разделы.


Этап 2: offers — единый список актуальных предложений (id, country, resort, hotel, stars, departure_date, nights, departure_city, price_from, price_date, photo, active). Страна задаётся slug из countries, фото — ключ image_dimensions. При active=false карточка не попадёт ни на главную, ни в каталог, ни в страну. show_country_offers=false скрывает подборки стран; true выводит только соответствующие активные предложения. Каталог собирает фильтры по фактически присутствующим странам.

rest_pages содержит тексты четырёх razdel-*.md и SHA исходников. Один шаблон rest.py; rest_section_order задаёт общий порядок checks/types/countries/hotels/faq/final. Страницы используют raw-режим emit: никаких замен исходных формулировок. hotels хранит по три редактируемые карточки на страну; None у image даёт тональный блок. Цены в этих карточках не предусмотрены. Источники и лицензии новых фото — docs/scheme2/d1/img/sources.json. Проверки перед публикацией собраны в otdyh/CHECKLIST.md.


Брендинг: branding в data.json задаёт файлы SVG/иконок; main.css содержит все цветовые токены и RGB-каналы прозрачностей. brand_icons() выдаёт SVG, PNG 32/512 и apple-touch 180 для каждого HTML. brand.py собирает актуальный styleguide.html и DESIGN.md внутри d1 из токенов CSS и ролей brand_palette; историческая дизайн-система в docs относится к другому состоянию сайта и не меняется. Смена логотипов не требует внешних ресурсов. SVG и предоставленные PNG-иконки хранятся в img/ без перекодирования. Размер логотипа в navigation.css учитывает его реальные пропорции 1193/440. Примеры отелей берутся из hotel_examples и стоят внутри карточек, когда good/note ещё пусты.

## Этап 3: онлайн и каналы связи

`online.py` подключает общие компоненты через контекст генератора: группы меню, связь, компактные услуги, страницу компании и финальную обработку метаданных. `data.json → contacts` — единственный источник Telegram username, MAX, каналов и статуса онлайн. Пустой `telegramUsername` и `max: "#"` намеренно не подменяются выдуманными аккаунтами. После заполнения username Telegram получает `?text=…`; MAX копирует сообщение перед открытием. При ошибке копирования доступно запасное окно с выделяемым текстом. До заполнения адреса Telegram оно же позволяет сохранить текст и позвонить.

`service_groups` управляет порядком трёх групп в шапке и каталоге. Содержимое кратких услуг пока требует согласования. `trust` и `safe_payment` — редактируемые черновые блоки. Команда находится в `o-nas/index.html#komanda`; прежний URL — статическая meta refresh-переадресация, не серверный 301.

Проверки этапа 3: `python tools/d1/check.py` (Playwright/Chromium — только инструмент разработки, не клиентская зависимость). Съёмка: `python tools/d1/screens.py`; актуальная галерея содержит 40 адресов и 86 JPEG с дополнительными состояниями главной.

## Этап 3.1

Тексты сообщений задаются в `data.json → pages → <путь> → messengerText`, служебный источник обращения — `topic`. Видимое поле направления не используется для служебных фраз. `MessageValidator` останавливает сборку при пустом сообщении, повторе H1 или склейке слов. В `foundedYear` указан год начала работы; стаж рассчитывается при сборке по Москве. Для доверия значение берётся из `trust[*].value`, либо вычисляется по `valueFrom: foundedYear`. Пустые показатели не выводятся; список собирается в d1/CHECKLIST.md с JSON-путями. Актуальный отчёт проверок — STAGE31_QA.json.
