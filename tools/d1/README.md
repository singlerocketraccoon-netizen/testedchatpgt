# Генератор дизайна 1

Только Python stdlib для сборки статичного HTML; клиент — HTML/CSS/vanilla JS, без fetch, CDN и библиотек. Область — `docs/scheme2/d1/` и `tools/d1/`.

```sh
python3 tools/d1/build.py
python3 tools/d1/check.py
python3 tools/d1/contrast.py
python3 tools/d1/extra_check.py
python3 tools/d1/screens.py
```

Проверка и съёмка используют установленный Chromium через Playwright — это инструмент разработки, не зависимость сайта. Ссылки относительные с `index.html`; проверка запускает сайт из подпапки. Съёмка: 390 px @2x и 1440 px @1x, JPEG 75, reduced motion, прокрутка до низа/обратно, ожидание шрифтов и декодирования фото, затем 500 мс. Галерея — `screens/pages/index.html`.

## Данные и шаблоны

- `build.py` — базовые HTML-компоненты и сборка стран без изменения их содержания.
- `stage4.py` — общий каркас утверждённой структуры 11.11: шапка, полосы обращения, главная, компания, контакты, отзывы, документы, FAQ и предложения.
- `content4.py` — чтение утверждённых `glavnyj-slajder.md`, `kak-my-rabotaem.md`, FAQ из `mango-structure-11-11.html`. Тексты и SHA-256 сопоставляются с JSON; расхождение останавливает сборку.
- `online.py` — сохранённые компоненты стран/услуг и проверка контекстных сообщений; старые генераторы доверия и контактов не вызываются.
- `rest.py` — общий шаблон четырёх авторских разделов отдыха; контент из `razdel-*.md` находится в `rest_pages`, порядок — `rest_section_order`. Исходные тексты не нормализуются.
- `brand.py` — дизайн-система и DESIGN.md из токенов `css/main.css` и `brand_palette`.
- `data.json` — единственный список `offers`, страны/услуги, сотрудники, тексты, контакты и данные метаданных. `pages.json` создаётся сборкой.

## Сроки и сообщения

`foundedYear` используется для вычисления стажа по Москве. `slides[*].showUntil` и `offers[*].showUntil` включают последний день показа; отбор учитывает дату сборки и `active`. Главная ограничивает предложения шестью, каталог и страницы предложений используют тот же отбор. Неактивные HTML предложений удаляются сборкой. Для статичного хостинга нужна повторная сборка после наступления срока.

`offers`: id, country, resort, hotel, stars, departure_date, nights, departure_city, price_from, price_date, photo, active, meals, travellers, showUntil, includes, notes. Неизвестные значения «уточняется» и примерные цены требуют согласования. `show_country_offers=false` скрывает предложения на страницах стран; список стран и услуг не меняется.

`pages.<путь>.messengerText` задаёт контекст сообщений страницы; `topic` — тему обращения. В этапе 4 сообщение окна включает тему и заполненные поля. Все кнопки каналов: MAX, затем Telegram; пустые аккаунты остаются `#`. MAX копирует сообщение перед переходом, Telegram использует `?text=…`; при невозможности доступно окно с копированием и телефоном. Сообщения проверяются при сборке. Данные не сохраняются и формы реально не отправляются.

Окна запроса/подбора — HTML с disabled fieldset до запуска JS, локальная валидация и очистка. Общая логика сайта — `js/main.js`; старые `inner.js`, `online.js`, `rest.js` не подключаются. Слайдер главной только ручной, карусель партнёров сохраняет прежнее поведение.

Изображения имеют источник, лицензию, размеры и контрольную сумму в `img/sources.json`. Сборка проверяет разрешение коммерческого использования активных фото. Юридические тексты оператора сохраняются отдельно от замены названия бренда.

Отчёты этапа 4: `STAGE4_QA.json`, `STAGE4_CONTRAST.json`, `STAGE4_EXTRA_QA.json`, `SCREENS_QA.json`. Предыдущие отчёты остаются историческими. Текущий список согласований — `CHECKLIST.md`.
