# Дизайн 1 · генератор · этап 6

```sh
python3 tools/d1/build.py
python3 tools/d1/check.py
python3 tools/d1/screens6.py
```

Сборка — Python stdlib. Сайт — статичный HTML/CSS/vanilla JS, без CDN, клиентских библиотек, fetch разметки, хранения данных и реального приёма заявок. Проверки используют установленный Chromium/Playwright и Node как инструменты разработки.

- `build.py` — базовые компоненты и порядок сборки; результат коммитится.
- `stage6.py` — действующие шапка, подвал, формы, темы, главная, каталог/предложения, услуги и общие страницы по `mango-structure-12-11-v2.html`.
- `country.py`, `rest.py` — прежние шаблоны стран и четырёх авторских разделов. В этапе 6 они подключают общую форму; их содержание сохраняется. `stage4.py` содержит переиспользуемые компоненты, брендинг и финальную обработку, не задаёт действующую структуру сайта.
- `brand.py` — палитра и дизайн-система из CSS-токенов. SVG и локальные шрифты не менялись; два RGB-канала масок фото стали нейтральными.
- `data.json` — страны, offers, 12 услуг, исходные тексты, контакты и флаги. `schema6` — извлечённые массивы редакции 2, SHA-256 проверяется при сборке. `read_schema6.cjs` нужен только проверкам точности извлечения, сборка Node не использует.
- `js/main.js` — единая валидация, сообщения, аналитические события, окна, ручной слайдер, меню-якоря услуг, фильтр каталога и панель. `js/country.js` — прежние климат/курорты/отели и связь выбранного месяца с общей формой.

У страны `published`; на главной действует `home_country_order`, в меню/каталоге/подвале алфавит. `showOffers` управляет предложениями отдельной страны. У предложения published, showUntil, featured и фиксированные departure_date/return_date/price_date; на главной четыре featured, у страны до четырёх. Снятые и истёкшие страницы удаляются сборкой. После наступления срока статичный сайт необходимо пересобрать.

`form()` — одна разметка трёх наборов полей, включая модальное окно и встроенные обращения. Каждый экземпляр содержит topic, page и пять UTM. month — ISO YYYY-MM, в сообщении используется русская подпись с годом. Телефон исключён из requestDetails; скрытые поля и UTM также не входят в сообщение. Цели — CustomEvent mango:goal: form_success с form_kind/topic; messenger_open с channel/topic; отдельные события предложения с offer_id. В события не включаются контакт или свободный текст.

Формы до JS заблокированы disabled fieldset, есть телефон. После локального успеха контакты очищаются. Аккаунты мессенджеров пока пустые: используется окно копирования с телефоном; MAX копирует сообщение перед переходом, Telegram использует ?text=. Внешний счётчик не подключён.

Услуги находятся на одной странице с id packages/custom/tours/cruises/hotels/tickets/transfer/visas/insurance/airport/experiences/weddings. Старые отдельные услуги и voprosy удаляются. Все URL относительные с index.html, фильтр каталога — ?country=slug, прокрутка при возврате остаётся нативной браузерной.

`check6.py` проверяет HTML/ссылки, источник, сохранность контента, формы/панель/каталог и публикацию; временные конфигурации JSON восстанавливаются в finally и сайт пересобирается. `--static` оставляет только статические проверки, `--gallery` добавляет технические HTML и галерею. `hero_check.py` требует зазор 24 px. `contrast5.py` проверяет главную, страны и отдых: обычный текст 4,5:1, крупный 3:1. Не запускайте съёмку одновременно с проверкой временных конфигураций каталога.

`screens6.py` снимает действующие страницы и 12 пар состояний: формы трёх типов, квиз, меню, открытую услугу, четыре слайда, раскрытый отдых и предложения. JPEG 75; 390 px @2x / 1440 px @1x, reduced motion, прокрутка вниз/обратно, ожидание шрифтов/фото +500 мс. Галерея — screens/pages/index.html. Предыдущие QA-файлы исторические, текущие — STAGE6_*.json.

Факты для согласования — docs/scheme2/d1/CHECKLIST.md. Источники и лицензии активов — img/sources.json; новые скачанные фото в этом этапе не добавлены.
