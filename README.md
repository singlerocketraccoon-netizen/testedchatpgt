# Манго Путешествия

Статичный дизайн турагентства, Астрахань. HTML, CSS и vanilla JavaScript; сборка и зависимости для запуска не нужны.

- [Главная](docs/index.html)
- [Дизайн-система](docs/styleguide.html)
- [Три первых экрана](docs/hero-variants.html)
- [Полная главная «Журнал»](docs/variants/v3/index.html)
- [Техническое оглавление](docs/prototypes.html)
- [Концепция](docs/DESIGN.md), [карта страниц](docs/SITEMAP.md), [SEO](docs/SEO.md)

Откройте `docs/index.html` как файл либо запустите `python3 -m http.server --directory docs`. Для GitHub Pages выберите опубликованную ветку и папку `/docs` в настройках репозитория. Права и аудитория репозитория автоматически не меняются.

Полные внутренние страницы относятся к следующему этапу. Нынешние вспомогательные адреса возвращают к соответствующим блокам главной. Форма проверяется локально, данные не отправляются и не сохраняются. Скриншоты должны создаваться GitHub Actions, а не храниться вручную.
