# Главная v5 «Бутик-отель»

Альтернативный дизайн в `docs/variants/v5/`: зелёный сплит-экран с арочным фото, фотогалерея настроений и предложения с табличной подачей параметров. Сохранены шапка, восемь блоков 01–08, все слайды, предложения, цены, даты, отзывы, вопросы, форма и подвал. Файлы за пределами v5, включая главную и v3, не изменялись.

## Концепция

Глубокий зелёный, кремовый текст и латунные линии создают ощущение спокойного бутик-отеля. Фото в арках связывают обложку, настроения, предложения и монограммы менеджеров. Светлые секции чередуются с зелёными; терракотовые кнопки поддерживают спокойный тон. Заголовки, цены и цитаты набраны локальной Lora, подписи и форма — локальной Manrope.

Палитра: зелёный `#173B32`, глубокий зелёный `#102E27`, кремовый `#F6F0E4`, светлый `#FFFAF0`, песок `#E9DFCF`, латунь `#CBB27E`, терракота `#A14F39`. Для латунных ссылок на светлом используется более тёмный `#78613A`.

От главной дизайн отличается отдельным текстовым полем на зелёном, арочным фото и предложениями в сетке 2 × 2. От v3 — симметричной фотогалереей, рамками, тёмными секциями и гарнитурой Lora вместо журнального коллажа и оглавления. Подробности: [NOTES.md](NOTES.md).

## Поведение и содержание

- Сохранены автосмена, прогресс, пауза, клавиатура, свайп и уменьшение движения.
- Аккордеон нативный; выбранное предложение подставляется в форму. Доступны WhatsApp, Telegram, MAX и звонок, проверка контакта и отдельное согласие, пустое по умолчанию.
- Формы работают локально, без передачи и хранения данных; после проверки поля очищаются. В событиях целей нет персональных данных. Без JS остаётся телефон, форма заблокирована.
- Для соблюдения запрета слова «вариант» применены две замены: «Обсудить поездку» и «Выберем предложение». Другие тексты сверены с исходной главной по всем блокам.

## Проверка

Chromium: 360, 390, 768, 1280 и 1440 px. Нет горизонтального скролла документа, наложений заголовков, ошибок консоли, не загруженных изображений и внешних запросов. Проверены все слайды, автосмена, пауза, touch-свайп, меню, FAQ, ссылки, согласие, локальный результат формы, отсутствие JS и `prefers-reduced-motion`. Контраст текста на тёмном фоне: кремовый 10,83:1, вторичный 7,27:1, латунь 5,98:1; текст основной кнопки 5,47:1.

Полный результат — [QA_REPORT.json](QA_REPORT.json). Открытие `file://` заблокировано политикой браузера окружения (`ERR_BLOCKED_BY_ADMINISTRATOR`); рабочие сценарии проверены через локальный сервер из подпапки, как на GitHub Pages.
