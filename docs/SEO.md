# SEO: правила следующего этапа

Основная задача главной — запрос «турагентство Астрахань», знакомство с агентством и переход к выбору отдыха. Страны, предложения, процесс и услуги получают самостоятельные задачи в SITEMAP.md, чтобы главная не подменяла весь сайт.

## Метаданные

- Главная: title «Турагентство в Астрахани — Манго Путешествия». Description коротко объясняет подбор, персонального менеджера и помощь с поездкой.
- На индексируемой странице один H1. На главной он состоит из маленькой строки «Турагентство в Астрахани» и крупной «Путешествия, которые подходят Вам». Другие слайды используют H2 и исключаются из доступной навигации, пока неактивны.
- Title до 60 символов, description до 160, уникальные и связанные с задачей страницы. Город указывать там, где он помогает запросу, без повторения в каждом абзаце.
- Будущий title страны: «Туры в {страну} из Астрахани — Манго Путешествия». Будущий title поездки: «{Курорт}: отдых из {город} — Манго Путешествия». Проверять фактическую длину после подстановки.
- Canonical и og:url абсолютные; относительные URL используются для переходов и ресурсов. `devfriends.ru` — рабочее предположение из задания, а не подтверждённый будущий домен. Перед публикацией заменить на домен владельца.
- OG: locale ru_RU, website, title, description и локально подготовленное изображение с абсолютным URL будущего сайта.

## Контент и разметка

Контент, карточки, цены, FAQ и состояния формы находятся в HTML. JS не загружает содержимое. В будущих странах и услугах описывать полезные условия: когда ехать, формат отдыха, вылеты, документы, что включено. Не подменять это перечнем поисковых фраз и не обещать наличие рейса или визу без проверки.

На всех страницах — TravelAgency с подтверждёнными адресом, двумя телефонами и часами. Не добавлять выдуманные rating, reviewsCount, юридическую дату основания и реквизиты. Год опыта 2010 не превращать автоматически в foundingDate юридического лица.

На главной FAQPage повторяет четыре видимых вопроса и ответа. В будущем: BreadcrumbList на внутренних, Article для статей, Product + Offer для конкретной поездки. В Offer цена в RUB **за двоих**; не добавлять InStock и даты действия цены без проверки. Скриншоты переписок и рейтинги не создавать самостоятельно.

## Перелинковка

Главная → настроение / страна → предложения → конкретная поездка → обсуждение. Страна связывается со своими турами и полезной статьёй; статья — с поездками по теме. Процесс, услуги и документы доступны из соответствующих вопросов и подвала. Не добавлять облако SEO-ссылок, сравнение с агрегаторами или фальшивую срочность.

Параметры `?mood=` и будущие фильтры каталога не должны создавать множество дублей: основная страница каталога получает canonical без фильтров, нецелевые комбинации закрываются от индексации. Сейчас файлы этих адресов служат только вспомогательными переходами к главной.

## Хлебные крошки и технические страницы

На будущей внутренней странице: Главная → Раздел → текущая страница. Последний пункт текстовый, ссылки и ресурсы относительные с явным index.html. Юридические страницы уже показывают крошки.

Styleguide, сравнение первых экранов, оглавление, v3, временные переходы и неутверждённые документы имеют noindex. Пример sitemap.xml содержит только готовую основную главную. robots.txt — заготовка для будущего домена; файл из подпапки GitHub Pages не управляет robots.txt всего github.io.

## Старые адреса

На этом этапе не требуется копировать старую структуру WordPress. При переезде проверить полный список старых адресов и настроить настоящие 301 на сервере. Предварительное соответствие:

| Старый адрес devfriends.ru | Будущий адрес | Статус |
| --- | --- | --- |
| `/` | `/` | новая главная |
| `/o-nas/` | `/o-nas/` | сохранить адрес |
| `/otzyvy/` | `/otzyvy/` | сохранить адрес и реальные источники |
| `/nashi-kontakty/` | `/kontakty/` | серверный 301 после проверки |
| `/individualnye-tury/` | `/uslugi/individualnye-tury/` | серверный 301 после проверки |
| `/kruizy-po-rossii-evrope-i-azii/` | `/kruizy/` | серверный 301 после проверки |

Текущие meta refresh не являются 301 и не подменяют план миграции. Старые страницы отзывов доступны как внешние источники; окончательное перенаправление не должно уничтожить возможность проверки цитат.
