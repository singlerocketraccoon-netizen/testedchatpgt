# Приёмка этапа 8

Источник — `mango-structure-12-11-v2.html`, тексты Египта редакции 3. Сборка — Python stdlib, HTML девяти стран отдаётся готовым; JS только меняет выбранные состояния. Сервер проверки запускается из `docs`, общие изображения и шрифты доступны.

## Автоматические результаты

- `python3 tools/d1/build.py`: 41 HTML-адрес; повторная сборка даёт одинаковые HTML.
- `python3 tools/d1/check8.py`: 41 адрес × 8 ширин × 3 движка = **984 проверки**, ноль ошибок геометрии и консоли. Движки: Chromium 156, Firefox 153, WebKit 26.5. Ширины: 360, 390, 768, 1024, 1280, 1366, 1440, 1920 px; высота 900 px.
- Независимое извлечение из схемы: **96 дословных фрагментов Египта**, четыре климатических массива, **252 ячейки** таблиц семи курортов совпали. Утверждённые тексты восьми разделов отдыха сохранены; допустимое отличие — точка/двоеточие в конце заголовка.
- Все `href`, якоря и изображения проверены; один H1, уникальные title/description, JSON-LD, пустое обязательное согласие и скрытые поля форм. Статистика ссылок и подробности — [QA8.json](QA8.json).
- Шапка отдельно измерена в трёх движках на 1024, 1100, 1200, 1280, 1366, 1440, 1920 px: отклонение центра менее 0,02 px; минимальный зазор до меню 36,06 px; переносов нет. Номер текстом виден только от 1440 px.
- Крошки: центры текста всех пунктов совпадают с допуском 1 px на всех страницах и ширинах. Ссылка имеет цель 44 px; длинная цепочка прокручивается внутри своей строки.
- Общие формы: строка «Пока не определились» помещается целиком. При 1440×900 кнопки форм стран и разделов отдыха видны без прокрутки. Кто едет/телефон — одна строка; состав и возраст детей ниже.
- Египет: выбор месяца/курорта и подпись станции Хургады для Эль-Гуны; переходы из курорта к отелям и климату; раскрытие всех курортов; фильтр, пустое состояние, окно отеля и Esc; справка первого экрана; подсветка всех шести пунктов меню; мобильная панель у конечной формы. Проверено на 390 и 1440 px в каждом движке.
- Сообщение отеля содержит выбранную тему и город вылета, но не телефон. Формы не отправляют и не сохраняют контакты.
- Предложения: `showOffers=true` с активным каталогом, `showOffers=false`, пустой каталог. Во втором/третьем случаях нет ни блока, ни ссылки меню; полоса «Другие даты» остаётся. Проверка — `tools/d1/offers8.py`.

Дополнительно: 20 измерений слайдера; 13 994 проверки контраста сплошных фонов и 903 выборки поверх фото, без нарушений; 18 состояний мобильной панели. Финальная проверка панели дополнительно измеряет, что все три кнопки находятся в одной строке и целиком внутри границ контейнера; перенос MAX/Telegram устранён. Крупные планы секций снимаются с временно скрытыми фиксированными элементами, чтобы шапка/панель не закрывали содержимое. Имена подробных файлов прежних инструментов сохранены: `STAGE7_HERO_QA.json`, `STAGE7_CONTRAST.json`, `STAGE7_PANELS_QA.json`.

## Полнота ширины, пункт 0.6

На 1280 и 1920 px проверены верхние единицы раскладки секций всех страниц, во всех трёх движках. Сетка/две колонки оцениваются вместе с соседним содержимым, а не по отдельной левой ячейке. Все карточки, списки проверок/возрастов, климат и формы заполняют контейнер либо отцентрированы. Детали предложения и его параметры растянуты по контейнеру, блок паспорта отцентрирован.

Осмысленные исключения в `width_exceptions`:

| Элемент | Страницы | Почему узкий |
|---|---|---|
| Кнопка «Все курорты» | Египет, Турция | Одиночное действие под полноширинной сеткой |
| Фильтр курорта | Египет, отели | Один компактный select над полноширинной подборкой |
| `legal-copy` | Политика, согласие | Только юридические абзацы с шириной чтения |
| Ссылка возврата | 404 | Одиночное действие |

Страница «Как мы работаем» сохраняет текст слева и оглавление справа. Пустая правая половина карточных блоков отдыха устранена: возраст/проверки — две колонки, маршруты — 3/2/1.

## Что подтвердить

[CHECKLIST.md](CHECKLIST.md) содержит требования по каждой стране. Египет: проверить все справочные факты, визу/платежи/связь/страховку, даты проверки, климат и тексты курортов; заменить Отели 1–3 и тональные иллюстрации; согласовать экскурсии. Остальные страны: предоставить недостающие данные, они не придуманы. Реальные отзывы, фотографии отелей/курортов и менеджеров остаются задачей владельца. Новых фотографий из сети не добавлялось.
