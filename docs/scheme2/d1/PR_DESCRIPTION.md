# Этап 2: предложения и разделы отдыха d1

На главной девять разных фото и короткие подписи. Добавлены лицензированные WebP семьи на пляже, лайнеров и дороги; источники/лицензии — img/sources.json. Добавлены переходы к процессу и всей команде, исправлены три адреса полосы доверия.

Предложения — один массив offers в data.json: три исходных и три новых (Таиланд, Вьетнам, Мальдивы). Главная — карусель 3/2/1 со стрелками и свайпом; [каталог](predlozheniya/index.html) — все активные предложения, фильтр по странам и сортировка. Состав/цены требуют согласования. Добавление и удаление — только изменение массива; active=false исключает карточку. Подборки на страницах стран выключены через show_country_offers=false; старые автономные карточки удалены. Флаг true проверен с совпадающей и отсутствующей страной. В подвал добавлены «Предложения», шапка сохранена.

Четыре новые страницы по единому шаблону tools/d1/rest.py:

Исходники razdel-*.md прочитаны из корня основной ветки. 281 строка сверена дословно, включая примеры, таблицы, формы, FAQ и сообщения. Для новых разделов отключена автоматическая замена формулировок. Порядок всех секций задаёт один массив rest_section_order; возможность перестановки проверена. Технические указания макета оформлены компонентами, а разделы «Проверить перед публикацией» собраны только в [CHECKLIST.md](otdyh/CHECKLIST.md). Соответствующие факты и условия имеют data-needs-approval.

На страницах — фото и форма, липкие якоря, проверки с примерами, четыре карточки формата, страны, вкладки отелей, FAQPage и повторная форма. Действия из стран переключают отели или подставляют страну в форму первого экрана. Отели — по три тональные редактируемые карточки без цен и выдуманных свойств. Сообщение менеджеру сохраняет точный текст исходника, для отеля добавляет его имя; копирование, MAX и Telegram доступны в окне. Формы только локально проверяют телефон/согласие, очищают поля и показывают благодарность. Отправки, хранения данных и внешней аналитики нет.
