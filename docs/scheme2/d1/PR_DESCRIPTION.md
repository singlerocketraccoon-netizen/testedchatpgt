# Схема 2 · d1: компактная команда и тонкая строка-акцент

Команда больше не занимает почти целый экран огромными портретами. На 1440 px интро стоит слева, три компактные карточки справа; высота секции **520 px**, карточки **376 px**. На 390 px — три горизонтальные карточки столбиком, секция **705 px**, без свайпа. Аватары 112 / 72 px, монограммы и тональные градиенты, тонкая рамка, чипы и кнопки MAX / Telegram; у руководителя деликатное выделение и редактируемая цитата для согласования.

Для строки «Подбор путешествий под Вас» выбран **Bad Script 22 px**, кремовый с непрозрачностью 88%, отступ до заголовка 10 px. Тонкий монолинейный штрих сохраняет личный тон, не конкурируя с Cormorant. На [accent-options.html](accent-options.html) собраны четыре одинаковых обложки: A — Bad Script, B — Marck Script, C — настоящий Cormorant Garamond Italic 300, D — Manrope с разрядкой и линией. Новые WOFF2 и лицензии OFL локальные; все русские буквы, включая Ё/ё, проверены по таблицам cmap. Caveat удалён.

Изменения этой доработки ограничены `docs/scheme2/d1/`: блок команды, четыре акцента, сравнение начертаний, локальные шрифты, документация и снимки. Остальные девять блоков, основной JS и корневой scheme2.md не менялись. В предыдущих коммитах этого PR есть ранее заказанные правки обложки/отзывов и согласованное дополнение scheme2.md; текущий коммит их сохраняет.

## Проверка

Chromium: 360, 390, 768, 1280, 1440 px. Побайтово проверен HTML за пределами команды и акцентов; вычисленные стили остальных девяти секций совпадают с предыдущей версией на пяти ширинах. Проверены слайдер и свайп, опрос, FAQ, форма с валидацией и очисткой, пустое согласие, карусель партнёров, меню, мобильная связь, кнопки сотрудников, отсутствие JS и reduced motion. На странице сравнения проверены шрифты, управление фото и мобильная ширина. Ошибок консоли, ресурсов, внешних запросов и передачи данных нет. file:// ограничен политикой Chromium окружения; сценарии проверены через HTTP с префиксом подпапки. Результаты — [QA_REPORT.json](QA_REPORT.json).

## Что проверить владельцу

Выбор акцента A, плотность команды и читаемость на телефоне. Заполнить реальные имена, фото, ссылки и специализации сотрудников, согласовать цитату руководителя (`data-needs-approval`). Новых отзывов, лиц и обещаний не добавлено. Формы ничего не отправляют и не сохраняют.

## Уточнение цитаты руководителя

Цитата стоит непосредственно под описанием, Cormorant Garamond Italic 300, до двух строк и на всю внутреннюю ширину карточки. Плашка перенесена к роли. Карточки одинаковой высоты: 376 px на компьютере, 180 px на телефоне. Блок не вырос: 520 px на 1440, около 705 px на 390; прежняя высота также сохранена на 768 и 1024. На шести ширинах проверены отсутствие обрезанного текста, максимум две строки, ширина цитаты, равные карточки и ссылки связи. HTML вне карточки руководителя и основной JS не изменены. Обновлены [команда 1440 px](screens/team-1440.jpg) и [команда 390 px](screens/team-390.jpg); полностраничные снимки и сравнение акцентов сохранены с предыдущего этапа.
