# Схема 2 · d1: правки заказчика от 9 ноября

Первый экран теперь занимает всю ширину и высоту окна (`100svh`, минимум 640 px), команда состоит из трёх вертикальных карточек, а блок 07 показывает только существующие реальные отзывы. Порядок 01–11, остальные восемь секций и общий стиль дизайна 1 сохранены.

## Что изменено

- **01:** убраны внешние поля, рамка и скругление обложки. Шапка прозрачная поверх живого фото с мягким зелёным затемнением; при прокрутке становится непрозрачной и закреплённой. Логотип центрирован, рукописная строка набрана локальным Caveat с кириллицей и лицензией OFL. Три равные нижние ячейки ведут к «О нас», процессу и отзывам.
- **06:** руководитель агентства и два менеджера. В каждой карточке портретная подложка 3:4 с условной монограммой, редактируемые имя, роль, помощь и специализация, ссылки MAX / Telegram. Новых лиц и имён нет. На телефоне — свайп с краем следующей карточки.
- **07:** заголовок «Отзывы», три исходные цитаты с прежними именами и направлениями. Для неизвестных дат — «Архив отзывов»; февраль 2019 у семьи Артёмовых обозначает месяц поездки. История удалена из HTML; в JSON-LD только TravelAgency и прежний FAQPage. Ссылка «Все отзывы» и строка связи сохранены. На телефоне — свайп.
- В конец корневого `scheme2.md` добавлен раздел «Правки заказчика от 9 ноября»; загруженный заказчиком текст сохранён целиком.

Песок, крем, терракота `#984B33`, приглушённый зелёный `#56614F`, Cormorant Garamond и Manrope сохранены. Общие ресурсы, другие дизайны и исходная главная не изменялись. Подробности — [NOTES.md](NOTES.md), исходные данные — [CONTENT_CHECK.json](CONTENT_CHECK.json).

## Проверка

Chromium: 360, 390, 768, 1280 и 1440 px, а также невысокие экраны. Проверены все четыре слайда, три якоря доверия, портретная пропорция 3:4, свайп команды и отзывов, опрос, форма, FAQ, партнёры и мобильная связь. Основной JS сохранён без изменений; передачи и хранения данных нет. Согласие пустое по умолчанию, формы без JS заблокированы. Ошибок консоли, ресурсов и внешних запросов нет.

Побайтовое сравнение подтверждает сохранность HTML блоков 02–05 и 08–11; отдельное сравнение вычисленных стилей — их прежний вид на пяти ширинах. Результаты — [QA_REPORT.json](QA_REPORT.json). Проверка `file://` ограничена политикой браузера окружения; рабочие сценарии выполняются через локальный сервер с префиксом подпапки, как на GitHub Pages.
