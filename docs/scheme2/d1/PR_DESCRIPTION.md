# Этап 1: главная d1 и общая навигация

«Страны» заменяет «Направления» в шапке, выпадающем и мобильном меню, подвале, хлебных крошках, блоке главной и H1/title каталога стран. Адреса napravleniya/… сохранены. «Пакетные туры» — первая услуга в меню. Все 33 HTML пересобраны через tools/d1/build.py.

Блок «Отдых, который Вам по душе» — шесть фотокарточек 3 × 2; на телефоне свайп. Ещё три карточки раскрываются по кнопке с aria-expanded. Использованы существующие лицензированные фото; новых загрузок нет. Четыре ссылки otdyh/… намеренно ведут на будущие страницы следующего этапа: отдых с детьми, тишина и море, пляж и прогулки, сервис и кухня.

Новое окно «Помогите выбрать» заменяет прежний четырёхшаговый опрос. Три группы чипов, условное поле дат, бюджет, маска телефона, отдельное согласие. Кнопка активна только при полном телефоне и согласии. «Горный воздух» выбирает «Горы»; первый экран и карточка отеля открывают то же окно. Фокус удерживается внутри; Escape и фон закрывают окно. После локальной проверки поля очищаются и показывается благодарность. Ничего не отправляется и не сохраняется; без JS формы заблокированы, телефон доступен.

В работе — четыре этапа; ячейка сопровождения на первом экране ведёт к этапу 4. На главной и странице отзывов добавлены ссылки Яндекс Карт и 2ГИС; оценки пустые, URL пока #, без логотипов. Источники существующих отзывов — редактируемые ссылки, цитаты не менялись.
