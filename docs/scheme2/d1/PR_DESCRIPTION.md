# Этап 7 — восемь разделов отдыха и единая типографика

Восемь разделов «Отдыха по душе» собраны по схеме 12.11 с полными утверждёнными текстами. Навигация стала крупнее, размеры текста сведены в общие токены, компания и команда объединены на странице «О нас». Палитра, логотип, содержание главной и данные стран сохранены.

1. **Сделано — разделы отдыха.** Один шаблон и восемь записей в JSON: четыре прежних раздела перестроены, четыре добавлены. Порядок: обложка → виды → страны → отели/туры/маршруты → проверки → все вопросы → конечная форма. У семьи четыре раскрывающихся возраста; в остальных разделах карточки, у своего маршрута три. Подборки имеют вкладки и по три карточки на страну; у своего маршрута вкладок нет. Фото/название открывают окно, CTA передают точный контекст общей форме и сообщению. Вкладка хранится в `?country=`, раскрытые пункты и прокрутка восстанавливаются после «Назад». Служебные строки исключены, непроверенные сведения имеют `data-needs-approval`. Главная, подвал и две кнопки услуг ведут на новые разделы. Круизы остаются в услугах.
2. **Сделано — шапка.** Контейнер до 1440 px, поля 40 px; логотип по центру, 64–68 px на компьютере и 44 px на телефоне. Меню 16 px, промежутки 40–44 px, цели от 44 px. На 1024–1279 телефон — значком. Страны в двух колонках, услуги около 600 px, компания компактным списком. Мобильное меню и управление клавиатурой сохранены.
3. **Сделано — типографика и стили.** Единственная шкала в `tokens.css`: текст 16/17 px, вводный 20, вторичный 14, служебный минимум 13, интерфейс/поля 16; заголовки по заданным clamp. Мелкая антиква заменена Manrope, небольшие заголовки от 22 px весом 500; абзацы до 70ch, интерлиньяж 1,6. Стили разделены на tokens/fonts/base/layout/components/header и home/country/rest/offers. Старые main/inner/navigation/online/stage4/stage5/stage6 CSS удалены, исключены 585 неиспользуемых селекторов. Сохранён Bad Script для акцента; Marck Script и отдельный лёгкий Cormorant Italic удалены. Основные WOFF2 предзагружены, запасные шрифты имеют size-adjust.
4. **Сделано — совместимость и проверка.** Добавлены vh перед svh/dvh, префикс backdrop-filter, классовая замена для :has(), запасное управление фокусом без inert. Нативные окна проверены в WebKit, клавиатура и возврат фокуса — во всех трёх движках. Для document.documentMode предусмотрена отдельная простая ES5-заметка с телефоном. Проверены десять ширин, плотность 1,25 и эквивалент масштаба 200%; горизонтального скролла, обрезания текста и текста меньше 13 px нет.
5. **Сделано — О нас.** Один блок: стаж, заголовок, прежний текст, место фотографии команды и три человека. Отдельных разделов компании/команды нет. Сохранены оба якоря `#company` и `#team` и прежний адрес команды как переход. Вверху только отзывы, контакты и документы. Меню компании содержит четыре ссылки, два перехода с главной ведут на `o-nas/index.html`.
