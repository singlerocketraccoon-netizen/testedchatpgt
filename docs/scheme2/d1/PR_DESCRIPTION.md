# Главная по схеме 2 в стиле дизайна 1

Новая страница находится в `docs/scheme2/d1/`. Структура собрана заново: блоки 01–11 идут строго по утверждённому изображению, включая шапку поверх четырёх слайдов, компактный выбор отдыха, три предложения, шесть стран, команду, отзывы и историю, контакты и партнёров. Основная главная, общие ресурсы и остальные дизайны не изменялись.

## Визуальные решения

Сохранены песок `#F3EEE4`, крем `#FAF7F1`, тёплый графит `#332D28`, терракота `#984B33`, приглушённый зелёный `#56614F`, Cormorant Garamond и Manrope. Фото и карточки мягко скруглены; чередование светлых поверхностей сохраняет воздух. Большая обложка объединяет фоновое фото с зелёным затемнением, центрированный бренд и полосу доверия из трёх ячеек.

## Поведение

- Четыре слайда: автосмена, ручная пауза, стрелки, счётчик, свайп, клавиатура и уменьшение движения.
- Плашки отдыха открывают четырёхшаговый опрос; карточка предложения переносит данные в форму блока 09.
- Нативный FAQ, медленная карусель партнёров с паузой при наведении и фокусе, ручная прокрутка на телефоне.
- Мобильная кнопка «Связаться»: телефон, MAX, Telegram, форма. У блока 09 она скрывается.
- Контакт и отдельное пустое согласие проверяются локально. Данные не передаются и не сохраняются; поля очищаются после результата. События целей не содержат ответов и персональных данных.
- Все шесть ссылок стран работают через небольшие страницы входа внутри разрешённой папки; выбранная страна возвращается в форму. Услуги открываются отдельной панелью.

## Приоритет схемы и согласование

В изображении три вопроса FAQ, в Markdown — шесть. Оставлены три вопроса изображения; ответы помечены `data-needs-approval`, JSON-LD совпадает с ними. Новые тексты используют строчное «вы» по схеме 2, реальные цитаты сохранены дословно. История основана только на Гранд-туре Аллы, без новых деталей. Имена команды и логотипы партнёров остаются редактируемыми.

Владельцу проверить композицию блоков и опрос, утвердить ответы FAQ, заполнить имена/фото команды, договорные логотипы, актуальные отели и цены, ссылки каналов, домен и юридические сведения. Источники и решения — [NOTES.md](NOTES.md), контроль исходных данных — [CONTENT_CHECK.json](CONTENT_CHECK.json).

## Проверка

Chromium: 360, 390, 768, 1280 и 1440 px. Проверены четыре слайда, все плашки опроса, шаг назад, проверка контакта/согласия, очистка полей, выбор предложения и страны, мобильная связь, клавиатура диалогов, FAQ, карусели, ссылки, фото и шрифты. Формы без JavaScript заблокированы. Ошибок консоли, ресурсов и внешних запросов нет. Результаты — [QA_REPORT.json](QA_REPORT.json).

Прямое открытие `file://` заблокировано административной политикой браузера окружения; рабочие сценарии проверены через локальный сервер из подпапки, как на GitHub Pages.
